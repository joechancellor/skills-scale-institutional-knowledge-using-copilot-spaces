# OctoAcme Project Management Docs

This README provides a centralized reference for all project management process documentation used by OctoAcme. It summarizes our approach and connects all detailed process docs to support team onboarding, consistent delivery, and continuous improvement.

## Project Management Processes Summary

OctoAcme delivers cross-functional projects using these key principles:
- Customer-first and iterative value delivery
- Clear ownership (Project Manager, Product Lead, Developers, QA, Stakeholders)
- Data-informed, evidence-based decision making
- Psychological safety and transparency
- Project lifecycle: Initiation → Planning → Execution → Release → Retrospective/Close
- Use of GitHub Projects, Issue templates, and living documentation for traceability and continuous improvement
